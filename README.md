# Single-cell Map of Early Lung Adenocarcinoma Uncovers Invasion-associated Tertiary Lymphoid Structures

This repository contains the R analysis code for the study: **"Single-cell map of early lung adenocarcinuma uncovers invasion-associated tertiary lymphoid structures"**

## Overview

This study provides a comprehensive single-cell RNA sequencing analysis of early-stage lung adenocarcinoma, revealing the role of tertiary lymphoid structures (TLS) in tumor invasion. The analysis includes:

- Single-cell transcriptomic profiling of lung cancer lesions
- T cell receptor (TCR) repertoire analysis
- TLS density and maturation analysis across disease stages
